# Projects

This folder is for tracking your projects.

Add a new markdown file for each project, for example:

- `projects/project-1.md`
- `projects/project-2.md`

Project template:

```md
# Project Name

- Status: Idea / In Progress / Complete
- Link: https://github.com/yourname/repo
- Tech stack: Python, Flask, etc.
- Start date: 2026-10-12
- Notes:
  - Goal 1
  - Goal 2
```

You can also keep this as a project index file and add one section per project below.
